# Cluide - Under Construction

This repository contains the "Under Construction" page for **cluide.de**. The site is built with basic HTML/CSS/JS and is designed to be hosted via GitHub Pages.

## Project Summary & Setup History

Below is a summary of the initial setup and configuration process for this project:

1. **Initial Setup**: 
   - Initialized a Git repository.
   - Added a `CNAME` file containing the custom domain (`cluide.de`) to automatically configure GitHub Pages.

2. **Project Renaming**:
   - The local directory was renamed to `Cluide`.
   - The primary HTML file was kept as `index.html` to ensure that GitHub Pages naturally serves it as the root domain page without users needing to type a specific file path.

3. **Design & Analytics Updates**:
   - Updated the page title to **"Under Construction"**.
   - Imported the `favicon.svg` from the Le Pannier Studios website to maintain brand consistency.
   - Added a legally compliant **Cookie Consent Banner** matching the layout of `lepannier.com`.
   - Integrated **Google Analytics** (`G-2D2CSH8VTH`). The analytics script is bundled into `script.js` and securely waits for the user to click "Accept" on the cookie banner before tracking, ensuring full privacy compliance.

4. **SEO & Indexing**:
   - Generated a `sitemap.xml` to allow the site to be registered and indexed quickly via **Google Search Console**.

5. **Deployment**:
   - All code (including the HTML, styling, scripts, favicon, and sitemap) was pushed to the `main` branch. GitHub Pages automatically builds and deploys the site to the live domain.
